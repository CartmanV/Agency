# Сайт направления «Агентства»

Единое веб-пространство по направлению: бэклог, дерево работ, агентства, метрики,
легенды. Статический сайт-просмотрщик; данные собираются из единого бэклога v5.

> Репозиторий приватный: внутри имена агентств и рабочие цифры.

## Запуск
```bash
pip3 install openpyxl markdown   # один раз
python3 build/build.py           # ../*v5*.xlsx → data/backlog.json
python3 -m http.server           # → http://localhost:8000
```
Открывать через http (не `file://`), иначе fetch JSON блокируется браузером.

## Структура
```
site/
├── index.html        входы в разделы
├── backlog.html      единый бэклог (таблица)
├── assets/           style.css · app.js
├── data/backlog.json собранные данные (219 итераций)
├── build/build.py    xlsx → json
├── CLAUDE.md         конвенции и состояние
└── README.md
```
